## 📱 Как загрузить проект на GitHub Pages с телефона Android

Вы можете легко запустить сайт на GitHub Pages прямо с Android-смартфона за пару минут!

### Шаг 1: Создайте аккаунт и репозиторий на GitHub

1. Откройте браузер на телефоне (Chrome, Kiwi, Opera) и зайдите на [github.com](https://github.com).
2. Войдите в свой аккаунт (или зарегистрируйтесь).
3. Нажмите кнопку **"+"** в правом верхнем углу ➔ **New repository**.
4. Введите название репозитория: `FOREX-ACADEMY-TJ`
5. Отметьте пункт **Public**.
6. Нажмите **Create repository**.

### Шаг 2: Загрузите файлы `index.html` и `README.md`

1. На странице созданного репозитория нажмите на ссылку **uploading an existing file** (или **Add file ➔ Upload files**).
2. Выберите файл `index.html` и `README.md` с вашего устройства.
3. Внизу нажмите зелёную кнопку **Commit changes**.

### Шаг 3: Включите GitHub Pages

1. Перейдите в вкладку **Settings** (Настройки) вашего репозитория.
2. В левом меню выберите пункт **Pages**.
3. В разделе **Build and deployment** ➔ **Branch**:
   - Выберите ветку `main` (или `master`).
   - Нажмите **Save**.
4. Подождите 1–2 минуты. GitHub сгенерирует готовую ссылку на ваш сайт, например:
   `https://<ваш-логин>.github.io/FOREX-ACADEMY-TJ/`
